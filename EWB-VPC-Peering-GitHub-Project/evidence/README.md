# Evidence Folder

Place your own redacted AWS console screenshots and terminal screenshots here after running the tests in `../docs/TEST-PLAN.md`.

Do not upload:
- `.pem` private keys
- AWS access keys or secret keys
- Passwords, session tokens, or recovery codes
- Unredacted billing details or account-sensitive information

Do not create fake screenshots or report expected results as if they were observed. Use real output from your AWS environment.
